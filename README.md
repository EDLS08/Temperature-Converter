# Temperature Converter CLI

A Java command-line application for converting temperatures between Celsius and Fahrenheit.

## Features

- Converts Fahrenheit to Celsius.
- Converts Celsius to Fahrenheit.
- Repeats the menu until the user chooses to exit.
- Handles invalid menu choices and non-numeric input without terminating unexpectedly.

## Requirements

- JDK 8 or newer.

## Run

From the repository root:

```bash
javac -d out src/TemperatureConverter.java
java -cp out TemperatureConverter
```

Enter decimal values with a dot, for example `36.5`.
