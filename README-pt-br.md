# Conversor de Temperatura CLI

Aplicação Java de linha de comando para converter temperaturas entre Celsius e Fahrenheit.

## Funcionalidades

- Converte Fahrenheit para Celsius.
- Converte Celsius para Fahrenheit.
- Repete o menu até que o usuário escolha sair.
- Trata opções inválidas e entradas não numéricas sem encerrar o programa inesperadamente.

## Requisitos

- JDK 8 ou superior.

## Como executar

Na raiz do repositório:

```bash
javac -d out src/TemperatureConverter.java
java -cp out TemperatureConverter
```

Digite valores decimais usando ponto, por exemplo `36.5`.
