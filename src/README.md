# Temperature Converter CLI

A simple Java console application that converts temperatures between Celsius and Fahrenheit. It features basic input validation and continuous execution using structured loops.

Available in other languages: [Português (Brasil)](README.pt-BR.md)

## Features
* **Celsius / Fahrenheit Conversion:** Converts values using basic mathematical formulas.
* **Input Validation:** Throws an `IllegalArgumentException` if the user selects an unavailable menu option.
* **Resilient Loop:** Uses a `while` loop combined with a `try-catch` block to handle exceptions and restart the application automatically instead of crashing.

## How to Run

### Prerequisites
* Java Development Kit (JDK) 8 or higher.

### Execution Steps
```bash
# 1. Clone the repository
git clone https://github.com

# 2. Access the directory
cd your-repository-name

# 3. Compile the application
javac TemperatureConverter.java

# 4. Run the program
java TemperatureConverter
```
